# SnipShot: Screen-Grounded Pedagogical Compilation (SGPC) Video Studio Engine

SnipShot transforms long-form programming lectures and educational videos into high-engagement, vertical 9:16 reels for mobile learners.

## Features
- **Mode A: Lecture Video -> 9:16 Reels**: Ultra-fast lecture video transcription, OCR screen grounding, 4-signal multimodal highlight ranking, perceptual 64x36 slide-skip gate, auto-indented code spotlight, and burning synchronized karaoke subtitles.
- **Mode B: Topic Prompt -> Explainer Reel**: 4-beat educational script compilation (Hook, Core Concept, Mutation/Contrast, Verification) with progressive IDE typing and Edge-TTS voiceover.
- **5-Node Dynamic Data-Flow Visualizer**: Interactive SVG pipeline demonstrating real-time math telemetry proofs.
- **Pre-Loaded Benchmark Lectures**: 1-click evaluation of real Python, Java Swing, Java OOP, and Git/Terminal lectures.
